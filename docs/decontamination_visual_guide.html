The Anatomy of a Leak: Prompts vs. Test Assertions

Not all leaks are created equal. In code and math reasoning benchmarks, contamination appears in two distinct forms:

ðŸ“ Type A: Prompt Contamination
def find_median_sorted_arrays(nums1, nums2):
    """Given two sorted arrays, return the median.
    Runtime must be O(log (m+n))."""

The problem description leaks. The model has seen the problem phrasing, but still must synthesize the function body unless accompanied by code.

ðŸ”‘ Type B: Test Assertion Contamination (Lethal)
assert find_median([1, 3], [2]) == 2.0
assert find_median([1, 2], [3, 4]) == 2.5
assert find_median([], [1]) == 1.0

The test assertions leak! The model can trivially memorize a lookup table: if nums1 == [1, 3]: return 2.0. Zero reasoning required.
